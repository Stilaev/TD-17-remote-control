# TD-17 Пульт — приложение для Android

Пульт для модуля Roland TD-17 на телефоне: выбор китов, громкость кита, педали хай-хэта, кросс-стика и метронома, микшер пэдов с панорамой, эффекты (Ambience, Reverb, Multi FX, компрессор), посылы и эквалайзер для каждого пэда, отмена изменений.

Подключение — через системный MIDI Android: по Bluetooth MIDI или USB-кабелем (через OTG-переходник). Интернет приложению не нужен. Работает на Android 8 и новее.

## Как получить APK без установки программ (через GitHub)

1. Зарегистрируйтесь на github.com (бесплатно).
2. Нажмите «New repository», назовите, например, `td17-pult`, нажмите «Create repository».
3. На странице репозитория нажмите ссылку «uploading an existing file».
4. Распакуйте архив на компьютере и перетащите в окно браузера **всё содержимое** папки `td17android`, включая скрытую папку `.github`. На Mac скрытые файлы показывает сочетание Cmd + Shift + точка.
5. Нажмите «Commit changes».
6. Откройте вкладку «Actions» — сборка запустится сама и займёт 3–6 минут.
7. Когда появится зелёная галочка, откройте запуск и внизу в разделе «Artifacts» скачайте `TD17-Pult-apk`. Внутри zip лежит `app-debug.apk`.
8. Перекиньте `app-debug.apk` на телефон и откройте. Android попросит разрешить установку из этого источника — разрешите.

Если в «Actions» красный крестик — откройте запуск и пришлите текст ошибки.

## Как собрать в Android Studio

Откройте папку `td17android` через File → Open, дождитесь синхронизации Gradle, подключите телефон по USB (с включённой отладкой) и нажмите ▶ Run. Готовый APK — через Build → Build APK(s).

## Подключение к модулю

1. На модуле: SETUP → Bluetooth → ON.
2. В приложении: «Подключить» → «По Bluetooth» → выбрать «TD-17 MIDI» в списке.
3. При первом подключении разрешите доступ к «Устройствам поблизости» (на Android 11 и старше — к геолокации и включите её: без этого Android не ищет Bluetooth-устройства).

Не подключайте модуль к другим MIDI-приложениям одновременно. Модели TD-17-L без Bluetooth подключаются USB-кабелем.

Если модуль не отвечает — проверьте в настройках приложения Device ID (по умолчанию 17, должен совпадать с SETUP → MIDI → SYS EX на модуле). Журнал MIDI в настройках показывает обмен с модулем.

Ручки VOLUME и PHONES на модуле аппаратные — по MIDI их изменить нельзя. Общую громкость регулирует фейдер «Кит». Изменения записываются прямо в кит, как при правке на модуле; «Отменить изменения» возвращает значения, прочитанные при загрузке кита.

## Устройство

| Файл | Что внутри |
|---|---|
| `app/src/main/java/ru/td17/pult/MainActivity.java` | Экран, разрешения, мост между интерфейсом и MIDI |
| `app/src/main/java/ru/td17/pult/MidiLink.java` | Поиск Bluetooth MIDI, подключение через MidiManager, USB, сборка входящих SysEx |
| `app/src/main/assets/index.html` | Интерфейс пульта и протокол Roland TD-17 (SysEx RQ1/DT1, карта параметров) |
| `.github/workflows/build-apk.yml` | Автоматическая сборка APK на GitHub |
